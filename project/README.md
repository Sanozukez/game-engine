# Projeto de Conteúdo do Game Engine

Este diretório representa o projeto mínimo de conteúdo do jogo.

Estrutura:
- scenes/: cenas do jogo
- terrains/: terrenos e mapas importados
- assets/: modelos, texturas, prefabs e recursos
- config/: configurações de cena e projeto

Uso:
- o editor cria e carrega cenas aqui
- terrenos importados são copiados para terrains/
- o projeto pode evoluir sem misturar conteúdo com código da engine
